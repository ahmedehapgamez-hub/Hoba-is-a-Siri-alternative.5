# Hoba 2.0 — Smart English Voice Assistant for Android

A modern, white-and-blue voice assistant inspired by Siri, built natively in Kotlin for Android.

## Key Features
- **Wake Word Detection:** Say **"Hoba"** (supports variations like *Hooba*, *Hobba*, *Huba*) followed by your command.
- **Voice Feedback (TTS):** Speaks back responses clearly in English.
- **Alarms & Timers:** Set alarms by voice (e.g., *"Hoba, set alarm for 7:30 AM"*).
- **WhatsApp Messaging:** Prepare and open WhatsApp chats by voice (e.g., *"Hoba, send WhatsApp to Ahmed saying I am on my way"*).
- **Device Control & Navigation:** Open any installed app, open Wi-Fi/Bluetooth/Display/Sound settings, toggle flashlight, search Google, or open websites.
- **Clean White & Blue UI:** Responsive interface compatible with modern Android versions (including Android 13–15 edge-to-edge display).

## How to Build on GitHub
1. Upload all files inside this repository to your GitHub repo.
2. Go to **Actions** -> wait for the **Build Hoba APK** workflow to finish with a green checkmark.
3. Download the **Hoba-APK** artifact and install it on your Android device.
